# script_system — система сценариев для лонгов «What if…»

Что внутри:

| Файл | Зачем |
|---|---|
| `ANALYSIS.md` | Доказательный разбор 46 историй конкурентов (числа, структура, психология) |
| `VIRAL_SCRIPT_DNA.md` | **Главный документ**: законы, скелет, хуки, эскалация, цена, кульминация, финал, запреты |
| `GENERATOR.md` | Конвейер «тема → оригинальный сценарий», конструкторы силы/эскалации/цены, библиотека угроз, защита от копирования |
| `QA_CHECKLIST.md` | 12 критериев качества + «сканер скуки» + протокол переписывания |
| `tools/lint_script.py` | Механическая проверка (ритм, цифры, ИИ-штампы, повторы, копирование) |
| `corpus_fingerprints.bin` | Только хеши 6-грамм корпуса конкурентов (для проверки копирования; тексты не хранятся) |
| `VARIETY.md` | **Антиповтор**: 9 скелетов из корпуса, 8 осей разнообразия, правила ротации, банк концовок и CTA |
| `COMPETITOR_PREMISES.md` | Что уже снято у конкурентов — не повторять |
| `channel_config.json` | Язык, режим, свой CTA, разрешённые бренд-фразы |
| `PERFORMANCE_LOG.md` | Сюда вносить просмотры/удержание: система будет уточнять ДНК |
| `scripts/` | Готовые сценарии (`INDEX.md` — журнал для ротации) |

## Как пользоваться
Просто напиши в сессии: **«Сценарий на тему: …»** (можно добавить `XL`, `S`, `drama`, `world`).
Скилл `viral-script-writer` сам подтянет ДНК, пройдёт конвейер, проверит и сохранит результат в `scripts/`.

Ручная проверка любого текста:
```
python3 script_system/tools/lint_script.py path/to/script.md --mode L
```

## Ограничения (честно)
- Линтер ловит дословные заимствования (≥~10 слов подряд) и фирменные фразы, но **не** слабые перефразы; за сюжетную оригинальность отвечает `COMPETITOR_PREMISES.md` и ручная проверка.
- Эвристика фактов — по ключевым словам; сами факты проверяются отдельно (GENERATOR шаг 4).
- Анализ без просмотров по роликам: частоты ≠ успех. Заполняй `PERFORMANCE_LOG.md`.
