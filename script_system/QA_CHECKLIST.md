# QA_CHECKLIST — проверка сценария перед выдачей (этап 6)

Выполняется **всегда**, после `lint_script.py`. Для каждого критерия оценка 0 / 1 / 2 и **одна строка доказательства** (номер предложения/цитата своего текста). Итог пишется в `qa.md`.

**Условие выдачи:** сумма ≥ 20/24, ни одного критерия 0, `lint` без `FAIL`. Иначе — переписать только слабые фрагменты и повторить (максимум 3 круга; потом пересмотреть идею в Premise Canvas).

| # | Критерий | 2 балла | 1 балл | 0 баллов | Как проверять |
|---|---|---|---|---|---|
| 1 | **Первые секунды** (первые ~14 слов) | Действие «you» + аномалия или опасность; ясная картинка | Картинка есть, но без аномалии/реакции | Вступление, вопрос, описание | Прочитать вслух 5 с. Показали ли что-то *необычное* и *с кем*? |

| 3 | **Скучные/лишние предложения** | Нет предложения, которое можно вырезать без потери события/числа/эмоции | 1–5 лишних | >5 лишних или абзацы «воды» | Пройти по тексту, вычёркивая; `flat-window` из lint |
| 4 | **Темп** | Новая мини-сцена каждые 40–70 слов; средняя длина предложения 5–8.5 | Есть 1 вялый участок 150+ слов | Эссеистика, длинные периоды | lint `rhythm`; подсчёт сцен |

| 8 | **Новые вопросы** | Каждый ответ порождает новый вопрос; всегда ≥2 открытых петли | Открытые петли не всегда есть | Все вопросы закрыты к середине | Реестр петель (DNA §11) |

| 11 | **Кульминация** | 9 шагов DNA §7; 2+ plants сработали; выбор стоит герою чего-то | 6–8 шагов | Победа силой без выбора | Пройти по шагам |

## «Сканер скуки» (применять после каждого прохода)
Разрезать текст на окна по 100 слов. В **каждом** окне должно быть минимум **два** из: новая локация, новый человек, новое число, раскрытие, поворот, смена эмоции, новая ставка. Нет двух — окно вырезать, сжать вдвое или вставить событие.

## Протокол переписывания
1. Выписать фрагмент (по номеру абзаца) и **причину** слабости.
2. Переписать **только** его, сохранив соседние предложения.
3. Повторить lint. Если фрагмент всё ещё слабый — искать причину **выше по цепочке** (слабый плант, слабая цена, не та угроза), а не полировать слова.
4. Записать в `qa.md`: что переписано и почему.

## Формат `qa.md`
```
Mode L · words N · lint: PASS (X warn)
1 Hook: 2 — "<цитата>"
...
12 Ending: 2 — "<цитата>"
Total: NN/24
Rewrites: (список)
Facts to double-check: (список из facts.md с confidence ≠ high)
```
