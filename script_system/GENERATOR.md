# GENERATOR — как из темы получить оригинальный сценарий

Вход: тема (одна фраза, можно мутная) + необязательно режим (`L` по умолчанию, `XL`, `S`) и вариант (`power` по умолчанию, `drama`, `world`).
Выход: `scripts/<дата>_<slug>/` → `script.md` (чистый текст озвучки), `beats.md`, `facts.md`, `qa.md`.

Основа — `VIRAL_SCRIPT_DNA.md`. **Тексты конкурентов при написании не открывать и не цитировать** (см. §10).

---

## Конвейер

```
1 Intake → 2 Premise Canvas → 3 Beat sheet → 4 Факты → 5 Черновик → 6 Правка → 7 QA (lint + 12 критериев) → 8 Выдача
                                                                         ▲_______________ переписать слабые места, ≤3 круга
```

### Шаг 1. Intake
1. Прочитать `channel_config.json` (язык, режим, CTA-стиль, свои бренд-фразы, запретные темы).
2. **Выбрать скелет и 8 осей по `VARIETY.md` до всего остального** (отличаться минимум по 5 из 8 осей от последних трёх). Затем свериться с `COMPETITOR_PREMISES.md` и `scripts/INDEX.md` (наши прошлые видео): тема не должна **материально** совпадать с уже снятой. Если совпадает, поменять угол: другая сила-правило, другое желание, другая цена, другая кульминация (минимум 3 из 4).
3. Если тема мутная («что-нибудь про деньги»), выбрать самому по §3, не задавая лишних вопросов. Спрашивать пользователя только если от ответа зависит жанр (драма vs «пауэр») и контекст не помогает.

### Шаг 2. Premise Canvas
Заполнить **целиком** (в `beats.md`):

```yaml
power: "одно предложение + границы (кто видит, когда работает, что НЕ делает)"
wish: "какое человеческое желание исполняет"
cost_inversion: "как исполнение обесценивает само желание (3 слоя: люди / я / смысл)"
hook_scene: "где, кто, ставка, видимая аномалия, число, реакция"
reveal_delay_words: 100-190
promise_ladder: ["малое", "большое", "огромное", "тёмное/выбор"]   # 3–4 вехи в разных сферах
now_small: "что герой реально умеет прямо сейчас (смешное)"
fact_bank: [8–9 пунктов — см. шаг 4]
escalation_rungs: ["rung1: place/audience/number", ... ≥4, каждая ×5–×100, новая среда]
complication: "как победа бьёт по системе"
plants: ["≥2 вещи/навыка/связи, которые сработают в кульминации"]
time_skip: "когда и где всё решится"
climax: {threat, clock_stat, why_not_someone_else, option_A, option_B, what_hero_loses, technique, outcome}
payoff: "что получает герой, чего сила не давала"
tail_hook: "кто/что и как открывает следующий уровень"
cta: "вопрос про силу + вопрос про жертву героя"
variation_axes: {hook_type, domain, setting_pair, cost_emphasis, climax_type, tail_type}
```

**Проверка желания→цены:** если цену можно заменить любой другой («просто заболел») — переделать: цена обязана вытекать из желания.

### Шаг 3. Beat sheet
Разложить 12 блоков из DNA §2 на слова (сумма ≈ целевое количество). Для каждой сцены записать: место → действие силы → реакция → доказательство (число/факт) → толчок. Вести **реестр петель** (DNA §11) и список **callback'ов** (2–3).

### Шаг 4. Факты (обязательно до черновика)
- Нужно 8–9 (L) / 4–5 (S) / 16+ (XL) фактов. Каждый — одно из трёх: **поднимает ставку**, **объясняет правило силы**, **задаёт часы в кульминации**.
- Для каждого в `facts.md`: формулировка, источник/тип (исследование, организация), уверенность (`high/med/low`).
- Если есть доступ в сеть, проверить числа поиском. Нет доступа — писать только то, в чём уверен, с «about/roughly», а `low` — удалить. **Не придумывать исследования, цифры, имена.**
- Размещение: зона 15–75% текста, не более 2 фактов на 100 слов. Структура: `Ситуация давит → факт (1–2 предложения) → связка с героем`.

### Шаг 5. Черновик
Порядок написания: **хук → кульминация → цена → всё остальное.** (Если эти три сильны, остальное правится быстро.)
- Сначала **три варианта первых 60 слов**, выбрать лучший по DNA §3 (число, ставка, реакция, причина скрыта).
- Писать вслух; предложение не длиннее одного дыхания.
- Не делать описаний «для красоты»: каждое предложение двигает действие или даёт информацию.

### Шаг 6. Правка (4 прохода)
1. **Вырезать**: всё, что не добавляет события/числа/эмоции/вопроса. Цель −10%.
2. **Конкретизировать**: убрать оценки («huge», «amazing»), заменить предметом/числом/действием.
3. **Ритм**: прочитать вслух; длинное предложение (>14 слов) разбить; стаккато-серии не длиннее 6 подряд (потом одно длиннее).
4. **Вариация**: заменить любую повторяющуюся конструкцию (§9 и DNA §12); если в тексте один и тот же оборот встретился дважды — второй переписать.

### Шаг 7. QA
1. `python3 script_system/tools/lint_script.py <script.md> --mode L` — исправить все `FAIL`, разобрать `WARN`.
2. Пройти 12 критериев `QA_CHECKLIST.md`, записать оценки в `qa.md`.
3. Слабое место (оценка 0–1 или `FAIL`) → **переписать только этот фрагмент**, затем снова lint. Максимум 3 круга; если после 3 кругов критерий ≤1, пересмотреть Premise Canvas (проблема в идее, а не в словах).

### Шаг 8. Выдача
- Сохранить 4 файла. В чат (по-русски, кратко): название, premise в 2 строки, длина/время, итог QA, что было переписано, какие факты стоит перепроверить.
- Добавить строку в `scripts/INDEX.md`.

## §3. Конструктор силы (если дана только тема)

Взять тему → применить один из ходов:

| Ход | Пример построения (не копировать) |
|---|---|
| **Инверсия** известного | «Не ты видишь будущее, а будущее видит тебя» |
| **Видимая метка** (число/статус/подсказка над людьми) | показывать то, чего люди сами о себе не знают |
| **Правило мира** («каждый раз, когда X, происходит Y») | счётчик, обмен, цена привычки |
| **Игровая механика в реальности** | сохранение, лимит, штрафы, лут |
| **Передача/обмен** | менять с кем-то часть тела/дар/время |
| **Масштаб** | всё становится 10× быстрее/тише/больше |

Тест на годность силы (все «да»): показывается **в одной картинке** без объяснений; даёт публичную ставку; есть исполненное **желание** (§2); цена **вытекает** из желания; можно построить **4 ступени масштаба**; можно придумать **физическую беду** (кульминация), где сила *бесполезна* без выбора.

Домены (чередовать между видео): социальный · физический · информация/знание · время/удача · вещество/техника · тело/биология · мир-масштаб.

## §4. Конструктор эскалации
Таблица (минимум 4 строки, лучше 5–6):

| # | Место | Кто свидетели | Число | Что нового (реакция) |
|---|---|---|---|---|
| 1 | | | 10–50 | друг теряет дар речи |
| 2 | | | 200–2000 | |
| 3 | | | 50 000 | СМИ |
| 4 | | | миллионы | институты |
| 5 | | | мир/планета | |

Каждая строка: новое место, новый тип свидетелей, число ×5–×100, **юмористическая деталь**, одна «побочная выплата» (деньги/слава/неловкость).

## §5. Конструктор цены
Для каждого слоя: **кто конкретно** (друг, мать, девушка) → **что бытово видно** (не звонит, ставит чашку молча) → **почему это про желание силы** → **фраза-удар** (≤8 слов).

## §6. Plants (задатки)
Минимум два. Типы: навык, предмет, нить/связь, чужая реплика, «слабое место» героя. Поставить до 40% текста **как шутку/бытовой эпизод**, а не как намёк. В кульминации сработает без объяснений.

## §7. Библиотека угроз для кульминации
Использовать реальные процедуры (так сцена убеждает и информирует). Перед публикацией факты проверить. **Избегать:** вооружённого насилия, самоповреждения, графических сцен, травли несовершеннолетних; рекомендуется ограничиться «природа/техника/здоровье» (рекламная безопасность канала).

| Угроза | Что делает герой | Проверяемый факт/часы |
|---|---|---|
| Остановка сердца | компрессии по центру груди 100–120/мин, 5–6 см, дефибриллятор (AED) | без помощи шанс выжить падает примерно на 7–10% в минуту |
| Сильное течение (rip) | не бороться, плыть параллельно берегу; пловцу — бросить плавучий предмет | течения вызывают около 80% спасений на пляжах |
| Давка | идти по потоку, руки перед грудью, не падать, не сопротивляться | опасная плотность — от ~5 человек на кв. метр |
| Лавина | маячок → зонд → лопата, копать со стороны склона вниз | в первые ~15 минут выживает подавляющее большинство, к ~35 минутам — меньшинство |
| Тонкий лёд | лечь, распределить вес, выползать по следу, не вставать | первые минуты — «шок холода»; правило «1-10-1»: 1 минута на дыхание, 10 минут на действия, до 1 часа до потери сознания |
| Машина в воде | ремень → окно → наружу → дети первыми | обычно плывёт всего 1–2 минуты |
| Анафилаксия | автоинжектор адреналина в бедро, вызвать скорую | эффект в течение минут, вызывать врачей всё равно |
| Инсульт | тест FAST (лицо, рука, речь, время) | мозг теряет миллионы нейронов каждую минуту |
| Подавился | 5 ударов по спине + 5 толчков в живот | помощь нужна в пределах минут |
| Пожар | пригнуться, закрыть двери, не лифт | дым опаснее огня; на выход иногда около 2 минут |
| Гроза на хребте | спуститься, рассредоточиться, присесть, ноги вместе | интервал вспышка-гром ≤30 с = в укрытие |
| Тяжёлое кровотечение | прямое давление, жгут выше раны | критично в течение нескольких минут |
| Перегрев/тепловой удар | охлаждение (вода/лёд), скорая | температура тела выше ~40 °C = неотложка |
| Отказ тормозов | накачка педали, понижение передачи, ручник плавно, увод на безопасную полосу | — |
| Землетрясение/обрушение | «пригнись-укройся-держись» | — |

Хорошо работает **двойной удар**: героя спасает не сила, а урок цены (например, раньше он выбирал «по числу», теперь выбирает «по человеку»).

## §8. Три варианта (сохраняют ядро DNA)

| | `power` (по умолчанию) | `drama` (из семейства A) | `world` (из B 11–13) |
|---|---|---|---|
| Длина | 1750 | 2000–2900 | 900–1300 |
| Голос | «you» | от 1-го лица «I» или «you» | «you», лекционно-юмористический |
| Ядро | сила + цена + жертва | ошибка героя из-за силы → потеря человека → искупление | вопрос «может ли человечество/мир сделать X?» |
| Особенность | стаккато, много сцен | **переосмысление правила на ~60%**; диалоги; мораль 2–4 фразы | аналогии из истории/биологии, «Here's the catch»-повороты, финал-выбор «кого бы ты взял?» |
| Вопросы в тексте | ≤3% | ≤7% | ≤5% |
| Кульминация | физическая угроза | выбор между правдой и выгодой в личной сцене | мысленный эксперимент с решением в конце |

## §10. Защита от копирования (этап 5)
1. Не открывать корпус при письме. В репозитории он не хранится, только хеши 6-грамм (`corpus_fingerprints.bin`).
2. `lint_script.py` блокирует: дословный отрезок ≥~10 слов из корпуса; сигнатурные фразы канала; предупреждает о заимствованных реквизитах/именах.
3. Сюжет проверяется по `COMPETITOR_PREMISES.md`: не повторять комбинацию «сила + кульминация».
4. Принципы переносятся, формулировки — никогда: если фраза «узнаётся» как фрагмент конкурента, она переписывается.
5. Допустимо повторять **структуру** (порядок блоков, пропорции, ритм), **типы** приёмов (лестница, цена, жертва) и **жанровые тропы** (спор, друг, толпа).

## §11. Ротация между видео
Для каждого видео фиксировать 6 осей (`variation_axes`). Следующий сценарий должен отличаться **минимум по 4 из 6** от последних пяти (см. `scripts/INDEX.md`). Это защита от «шаблонного» ощущения канала.

## §12. Формат файла `script.md`
```
# <Рабочее название>
<чистый текст озвучки, абзацы по 1–4 предложения>
```
Без ремарок, без «[music]», без заголовков внутри. Числа цифрами. Абзац = смена кадра/момента (удобно для дальнейшей раскадровки).
